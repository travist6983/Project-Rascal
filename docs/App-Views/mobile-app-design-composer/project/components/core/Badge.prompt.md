Names the kind of a prompt or saved entry. Five kinds, fixed colors.

```jsx
<Badge kind="voice" />
<Badge kind="did">DID IT</Badge>
<Badge kind="photo" bare />
```

The kind→color mapping is not decorative: terracotta means the phone records
something, periwinkle means you write something, sage means nothing is saved at
all. Never recolor a badge to fit a layout.
