Point at it.

The hand opens — outer cards last, on a 45ms stagger, so it reads as a fan rather than as a scale. Closing has no stagger, so it snaps shut instead of unravelling. Keyboard users get the same thing on :focus-visible, and anyone who has asked their system for less motion gets none.

Why the mask carries the same class as the cards

A knockout mask is built from where the cards are. Left static, the gap stays put while the card rotates away and the mark tears. The mask's shapes carry the same class and the same custom properties as the cards they mirror, so one rule moves both.

It matters more than tidiness. The masthead is translucent with a backdrop filter, so page content scrolls underneath and tints it continuously — there is no solid colour a stroke could have used that stays right at every scroll position.

The CSS

.vellum-logo { display: inline-block; line-height: 0; color: #23253C; border-radius: 6px; }
.vellum-logo svg { display: block; height: 34px; width: auto; overflow: visible; }

/* One rule, two jobs. The cards carry this class and so do the shapes inside each
   knockout mask, so the gap between two cards travels with the cards rather than staying
   where they used to be. Without that the mark tears the moment it opens. */
.vellum-logo__card {
  transform: rotate(calc(var(--a) * 1deg)) translateY(-120px);
  transition: transform 260ms cubic-bezier(.4, 0, .2, 1);
}
/* Opening staggers from the middle outward; closing does not, so the hand snaps shut
   rather than unravelling. The delay lives in the hover rule for exactly that reason. */
.vellum-logo:hover .vellum-logo__card,
.vellum-logo:focus-visible .vellum-logo__card {
  transform: rotate(calc(var(--a) * 1.45deg)) translateY(-127px);
  transition: transform 460ms cubic-bezier(.22, .9, .28, 1);
  transition-delay: calc(var(--i) * 45ms);
}
.vellum-logo:focus-visible { outline: 2px solid #C05A2B; outline-offset: 6px; }

@media (prefers-reduced-motion: reduce) {
  .vellum-logo__card,
  .vellum-logo:hover .vellum-logo__card,
  .vellum-logo:focus-visible .vellum-logo__card {
    transform: rotate(calc(var(--a) * 1deg)) translateY(-120px);
    transition: none;
  }
}

One caveat. The fan opens past the edge of its own box, so the svg is overflow: visible and the layout never shifts when it moves. At a 34px height it reaches about 6px left, 2px down and 0px right of its box. A parent with overflow: hidden clips the open state.
