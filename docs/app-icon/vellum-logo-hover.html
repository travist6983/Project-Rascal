The hand opens — outer cards last, on a 45ms stagger, so it reads as a fan rather than as a scale. Closing has no stagger, so it snaps shut instead of unravelling. Keyboard users get the same thing on :focus-visible, and anyone who has asked their system for less motion gets none.

34 — header

One caveat worth knowing. The fan opens past the edge of its own box, so the svg is set overflow: visible and the layout does not shift when it moves. A parent with overflow: hidden will clip the open state — if the header has one, give this element room rather than turning the overflow off.

The CSS

.vellum-logo {
  display: inline-block;
  line-height: 0;                 /* an inline-block wrapping an svg gets a descender gap */
  border-radius: 6px;
}
.vellum-logo svg {
  display: block;
  height: 44px;                   /* the only size you set — width follows the viewBox */
  width: auto;
  overflow: visible;              /* the fan opens past its box; see the note below */
}
.vellum-logo .vl-card {
  transform: rotate(calc(var(--a) * 1deg)) translateY(-120px);
  transition: transform 260ms cubic-bezier(.4, 0, .2, 1);
}
/* Opening staggers from the middle outward; closing does not, so the hand snaps shut
   rather than unravelling. The delay lives in the hover rule for exactly that reason. */
.vellum-logo:hover .vl-card,
.vellum-logo:focus-visible .vl-card {
  transform: rotate(calc(var(--a) * 1.45deg)) translateY(-127px);
  transition: transform 460ms cubic-bezier(.22, .9, .28, 1);
  transition-delay: calc(var(--i) * 45ms);
}
.vellum-logo:focus-visible {
  outline: 2px solid #C05A2B;
  outline-offset: 6px;
}
@media (prefers-reduced-motion: reduce) {
  .vellum-logo .vl-card,
  .vellum-logo:hover .vl-card,
  .vellum-logo:focus-visible .vl-card {
    transform: rotate(calc(var(--a) * 1deg)) translateY(-120px);
    transition: none;
  }
}

Why this one strokes its card gaps in white when every other file in this directory cuts them out. A knockout needs to know nothing about the background, which is what makes the static files safe anywhere — but the mask is built from where the cards are, so the moment one rotates away its notch stays behind and the mark tears. A stroke moves with its card. That trades ground-independence for motion, which is the right trade here and the wrong one everywhere else.
